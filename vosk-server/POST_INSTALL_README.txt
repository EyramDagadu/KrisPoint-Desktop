========================================
KrisPoint Voice Recognition Setup
========================================

IMPORTANT: One-Time Setup Required!

After installing KrisPoint, you need to install the voice recognition 
components ONCE on your computer.

STEP-BY-STEP INSTRUCTIONS:
========================================

1. Install Python 3.10 or Later
   - Download from: https://www.python.org/downloads/
   - During installation: CHECK ☑ "Add Python to PATH"
   
2. Run the Dependency Installer
   - Double-click: INSTALL_DEPENDENCIES.bat
   - Wait for it to complete (may take 5-10 minutes)
   - You'll see "SUCCESS!" when done

3. Start KrisPoint
   - Voice recognition will now work automatically!

========================================

TROUBLESHOOTING:
========================================

If voice recognition doesn't work:

1. Make sure Python 3.10+ is installed
   - Open Command Prompt
   - Type: py -3.10 --version
   - Should show: Python 3.10.x or higher

2. Re-run INSTALL_DEPENDENCIES.bat
   - Right-click → Run as Administrator
   
3. Check if you have an NVIDIA GPU
   - Voice recognition uses GPU for speed
   - Works on CPU too (just slower)

========================================

NEED HELP?
Contact KrisPoint support with:
- Windows version
- Python version (from step 1 above)
