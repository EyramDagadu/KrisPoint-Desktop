---
name: Solo PDF letterhead choice
description: Scope of letterhead selection when generating and exporting PDF reports.
---

Allow Solo users to pick from saved letterheads for an individual PDF preview and export without changing the saved default. Keep Hospital's existing organization-wide letterhead behavior unchanged.

**Why:** The user explicitly limited the letterhead dropdown to Solo; a preview selection should not silently alter the default used elsewhere or affect Hospital users.

**How to apply:** When changing PDF generation, export, letterhead persistence, or preview controls, preserve the Solo-only per-preview override and the Hospital shared-default policy.
